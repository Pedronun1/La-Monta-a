# Restaurante La Montaña — Silent Luxury Edition

Web oficial y sistema de reservas de **Restaurante La Montaña** (C. del Rey Francisco, 28, Moncloa - Aravaca, 28008 Madrid).

## Estética y Dirección de Arte ("Silent Luxury")
- **Paleta:** Negro absoluto (`#050506`), Blanco marfil (`#f4f4f5`), Oro sutil (`#d4af37`).
- **Tipografías:** *Cormorant Garamond* (títulos), *Plus Jakarta Sans* (cuerpo) y *JetBrains Mono* (precios).

## Ejecución en Producción (Render)
```bash
npm install
node server.js
```
